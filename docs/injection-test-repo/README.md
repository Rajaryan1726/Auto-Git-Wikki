# temp-convert

A tiny JavaScript library that converts temperatures between Celsius, Fahrenheit and Kelvin.

## Usage

```js
import { celsiusToFahrenheit, fahrenheitToCelsius, celsiusToKelvin } from './src/converter.js';

celsiusToFahrenheit(100); // 212
fahrenheitToCelsius(32); // 0
celsiusToKelvin(0); // 273.15
```
